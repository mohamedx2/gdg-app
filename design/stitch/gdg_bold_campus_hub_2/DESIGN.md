## Brand & Style

This design system establishes an energetic, high-precision dark interface tailored for collegiate developer communities, hackathons, and technical workshops. It fuses the optimistic, primary-driven Google ecosystem palette with an elite developer tool aesthetic—balancing accessible community warmth with the crisp utility of a command center.

### Design Movement & Visual Character
- **Developer-Centric High-Contrast:** Built on an ultra-deep charcoal ground layered with sharp, architectural borders and luminous chromatic highlights.
- **Controlled Luminescence:** Accent colors emit deliberate, low-radius photonic glows against nested container surfaces, providing rapid semantic scanning without visual fatigue.
- **Precision Engineered:** Combines human-friendly geometric sans typography for headings and interface navigation with disciplined monospaced metrics, terminal tags, and status readouts.
- **Atmosphere:** Forward-looking, technically astute, collegiate, and collaborative.

## Colors

The palette leverages a structured 3-tier dark foundation accented by Google’s four primary brand spectrums. Color is deployed functionally: structural backdrops remain muted to let data visualizations, code highlights, and interactive states command visual priority.

### Surface Tiers
- **Canvas Base (`#0C0E14`):** Global viewport background, negative space, and outer gutter wells.
- **Surface Level 1 (`#131722`):** Primary cards, global navigation bars, tab rails, and large parent containers.
- **Surface Level 2 (`#1C2234`):** Elevated child panels, inputs, active states, code execution shells, and hover targets.
- **Surface Level 3 (`#252C42`):** Popovers, dropdown menus, floating tooltips, and modal overlays.

### Chromatic Accents
- **Google Blue (`#4285F4`):** Primary brand identity, focal call-to-action buttons, active navigation markers, and telemetry links.
- **Google Green (`#34A853`):** Secondary operations, successful builds, verified badges, active event states, and live attendees.
- **Google Red (`#EA4335`):** Tertiary accents, deadline counters, urgent broadcast announcements, and error indicators.
- **Google Yellow (`#FBBC04`):** Quaternary warnings, hackathon track stars, community spotlight awards, and pending review tags.

### Functional Structural Values
- **Subtle Structural Border (`#2A324B`):** Standard container boundaries, table dividers, and input borders.
- **High-Contrast Border (`#3D4869`):** Hover rings, focused inputs, and active interactive borders.
- **Text High-Emphasis (`#F1F5F9`):** Headings, active label text, key metrics.
- **Text Medium-Emphasis (`#94A3B8`):** Body copy, auxiliary descriptions, inactive menu items.
- **Text Low-Emphasis (`#64748B`):** Monospace metadata, timestamps, input placeholders.

## Typography

Typography establishes an intentional cadence between human dialogue and programmatic telemetry:

- **Plus Jakarta Sans** powers structural prose, section headers, navigation bars, and marketing narrative blocks. Its contemporary geometric curves maintain approachability within high-density layouts.
- **JetBrains Mono** is reserved exclusively for developer tokens: terminal snippets, git commits, attendee timestamps, session capacity ratios, and technical pill badges.
- **Scale Strategy:** Display headings step down progressively on viewports under 768px (`display-hero-mobile`, `headline-lg-mobile`) to protect vertical scanning speed and avoid awkward label wrap on handheld devices.

## Layout & Spacing

The system runs on a strict 8-point layout rhythm, prioritizing structural density for dashboards while permitting open breathing room for hackathon hero areas.

### Grid Framework
- **Desktop (≥1200px):** 12-column fluid grid, 24px (`gutter-desktop`) gutters, 40px (`margin-desktop`) outer margins. Max container constraint: 1360px.
- **Tablet (768px – 1199px):** 8-column fluid grid, 20px (`gutter`) gutters, 24px (`margin-tablet`) outer margins.
- **Mobile (<768px):** 4-column fluid grid, 16px gutters, 16px (`margin`) outer canvas margins.

### Gap and Reflow Mechanics
- Complex 3-column event feeds on desktop collapse to 2 columns on tablet and a single continuous stack on mobile.
- Use `space-md` (16px) for intra-component spacing (between inputs and field labels).
- Use `space-lg` (24px) for card body padding and element group grouping.
- Use `space-xl` (32px) for structural section separation within dashboard modules.

## Elevation & Depth

Depth is established through physical surface stacking coupled with hairline contrast boundaries, bypassing heavy, muddy drop shadows in favor of localized luminous radiance.

### Layering Hierarchy
1. **Base Layer (`#0C0E14`):** Flat void canvas.
2. **First Elevation (`#131722`):** Ground cards. Bounded by a 1px solid border (`#2A324B`).
3. **Floating & Hovered Elements (`#1C2234`):** Lifted cards and action bars. 1px solid border (`#3D4869`) with an ambient drop shadow: `0 8px 24px -4px rgba(0, 0, 0, 0.45)`.
4. **Overlay Planes (`#252C42`):** Modals, flyouts, contextual command palettes. 1px solid border (`#4285F4` at 40% opacity) with shadow: `0 16px 40px -8px rgba(0, 0, 0, 0.75)`.

### Chromatic Glow Accents
Interactive and focal elements use chromatic edge glows instead of generic grayscale elevation:
- **Blue Neon Edge (Primary Interactive):** `box-shadow: 0 0 16px rgba(66, 133, 244, 0.25)`.
- **Green Telemetry Edge (Live Events / Active Hosts):** `box-shadow: 0 0 14px rgba(52, 168, 83, 0.25)`.
- **Red Alert Edge (Critical Deadlines / Capacity Full):** `box-shadow: 0 0 14px rgba(234, 67, 53, 0.25)`.

## Shapes

The geometric framework balances friendly rounded curvature with developer-grade precision:

- **Base Radius (`0.5rem` / 8px):** Applied to inputs, buttons, nested code snippet containers, and segment controls.
- **Card & Panel Radius (`1rem` to `1.25rem` / 16px – 20px):** Applied to major dashboard containers, campus event cards, and workspace zones.
- **Dialog & Modal Radius (`1.5rem` / 24px):** Applied to floating modals and showcase viewports.
- **Full Radius (Pill / 9999px):** Strictly reserved for badge chips, status indicators, and avatar wrappers.

## Components

### Buttons
- **Primary:** Background `#4285F4`, text `#FFFFFF`, font `Plus Jakarta Sans` semi-bold (14px). Height 40px, padding horizontal `1.25rem`, border radius 8px. Hover: background `#3367D6` with blue glow (`0 0 14px rgba(66, 133, 244, 0.35)`).
- **Secondary / Ghost:** Background `transparent`, border 1px solid `#2A324B`, text `#F1F5F9`. Hover: background `#1C2234`, border-color `#3D4869`.
- **Destructive:** Background `rgba(234, 67, 53, 0.12)`, border 1px solid `#EA4335`, text `#EA4335`.

### Input Fields
- **Container:** Background `#131722`, border 1px solid `#2A324B`, border radius 8px, height 42px, padding horizontal `1rem`. Text `#F1F5F9` (14px `Plus Jakarta Sans`). Placeholder `#64748B`.
- **Focus State:** Border 1px solid `#4285F4`, box-shadow `0 0 0 1px #4285F4, 0 0 12px rgba(66, 133, 244, 0.2)`. Outline: none.
- **Code Inputs & Search:** Integrate monospace prefixes (e.g., `gdg://` or `$` prompts) in `JetBrains Mono` rendered in `#64748B`.

### Cards & Event Panels
- **Structure:** Background `#131722`, 1px solid border `#2A324B`, border radius 16px (20px for large hero cards), internal padding `1.5rem`.
- **Hover State:** Border color `#3D4869`, subtle vertical transform (`-2px`), and background `#171C2B`.
- **Header Accent:** Optional top border strip (2px) in Google brand blue, green, yellow, or red to denote hackathon category.

### Chips & Badges
- **Status Pills:** Height 24px, padding horizontal `0.625rem`, border radius 9999px. Typography: `label-tag` (`JetBrains Mono` 11px uppercase).
- **Variants:**
  - *Live / Active:* Background `rgba(52, 168, 83, 0.12)`, border 1px solid `rgba(52, 168, 83, 0.4)`, text `#34A853`. Includes an animated pulsing 6px dot.
  - *Workshop Track:* Background `rgba(66, 133, 244, 0.12)`, border 1px solid `rgba(66, 133, 244, 0.4)`, text `#4285F4`.
  - *Expiring / Priority:* Background `rgba(234, 67, 53, 0.12)`, border 1px solid `rgba(234, 67, 53, 0.4)`, text `#EA4335`.

### Checkboxes & Radio Controls
- **Unchecked:** Size 18px × 18px, background `#131722`, border 1.5px solid `#2A324B`, border radius 4px (checkbox) / 50% (radio).
- **Checked:** Background `#4285F4`, border-color `#4285F4`, box-shadow `0 0 8px rgba(66, 133, 244, 0.4)`. White inner check icon / 6px radial dot.

### Lists & Data Rows

- **Row Anatomy:** Padding `0.875rem 1rem`, transition background `150ms ease`. Hover background: `#1C2234`.

### Terminal & Code Blocks

- **Top Window Bar:** Three 10px dot markers (`#EA4335`, `#FBBC04`, `#34A853`), title text in `JetBrains Mono` 12px `#94A3B8`.
